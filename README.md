# 고스톱 점수계산

가족끼리 실제 화투를 칠 때 폰으로 점수와 돈을 계산하는 웹 앱 (3인 · 3-5-7 점수 룰).
설치 없이 브라우저에서 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있다(인터넷 없어도 동작).

## 계산 규칙 (확정 2026-10-29)

| 항목 | 규칙 |
|---|---|
| 판돈 | 3·4점 1,000원 · 5·6점 2,000원 · 7·8점 3,000원 … (홀수 점수마다 +1,000, 짝수는 아래 홀수로 인정) |
| 고 | 1고 +1점 · 2고 +2점 · 3고부터 (점수+고)에 ×2, 4고 ×4, 5고 ×8 … |
| 흔들기·폭탄 | 1번마다 점수 ×2 |
| 배수 적용 순서 | 최종 점수 = (기본 점수 + 고) × 고 배수 × 흔들기 배수 → 최종 점수로 판돈 결정 |
| 박 | 피박·광박·멍박 1개마다 그 패자가 내는 돈 ×2 (피박+광박 = ×4) |
| 독박 | 독박한 사람이 패자 몫 전부(다른 패자의 박 포함)를 혼자 냄 |
| 첫뻑 | 누르는 즉시 그 사람 +2,000 (나머지 두 명 각 −1,000) · 한 판에 1인 1회, 여러 명 가능 · 배수 없음 |
| 나가리 | 승자가 없거나 3점 미만. 다음 판 판돈 ×2, 연속이면 ×4, ×8 … (그날 안에서만 이어짐) |
| 승·패 | 승 = 그 판 승자, 패 = 승자가 있는 판의 나머지(독박 포함), 나가리는 셈하지 않음. 누적 금액·지난 기록·복사 글에 표시 |
| 게임 종료 | 누르기 전까지는 앱을 꺼도·자정이 지나도 같은 게임으로 이어짐(입력 중인 판도 자동 저장). 누르면 판별 기록을 정리하고 시작한 날짜로 사람별 최종 금액만 남김 |

예: 기본 4점 · 3고 · 흔들기 1번 → (4+3)×2×2 = 28점 → 판돈 13,000원.

## 화면 (하단 탭 4개)

- **게임** — 누적 금액 + 판 입력 (① 첫뻑 → ② 승자 → ③ 기본 점수·고·흔들기 → ④ 패자별 박·독박)
- **오늘 기록** — 판별 기록, 수정·삭제, 🏁 오늘 게임 종료
- **지난 기록** — 날짜별 최종 금액, 카톡 붙여넣기용 복사
- **설정** — 이름 변경, 규칙 안내

기록은 그 폰의 브라우저 저장소(localStorage)에만 남는다. 앱 데이터를 지우면 기록도 사라진다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 전체 (HTML·CSS·JS 한 파일) |
| `calc.js` | 계산 규칙 — 화면과 분리된 순수 함수 (브라우저·Node 공용) |
| `calc.test.js` | 계산 테스트 (엑셀 실제 기록 + 규칙별 사례 + 전수 검사) |
| `sw.js` · `manifest.webmanifest` · `icons/` | 홈 화면 설치·오프라인 실행·앱 아이콘 (`icons/` 는 `Main_Icon.jpg` 원본에서 생성) |

## 개발

```bash
node calc.test.js
```

```bash
python -m http.server 5173 --bind 127.0.0.1
```

두 번째 명령 후 http://localhost:5173 에서 확인. 규칙을 바꾸면 `calc.js` 와 `calc.test.js` 를 함께 고친다. 배포할 때마다 `sw.js` 의 `CACHE`(gostop-vN)·`FILES` 의 `calc.js?v=N` 과 `index.html` 의 `calc.js?v=N` 을 같은 숫자로 올린다(화면과 계산 파일이 다른 버전으로 섞이지 않게).
